# Source: https://learn.microsoft.com/en-us/windows/win32/debug/system-error-codes--1700-3999- (RPC_S_SERVER_UNAVAILABLE, 1722 = 0x6BA : « The RPC server is unavailable. », traduit) ; que l'inscription réelle auprès d'une autorité dont CertSvc est arrêté renvoie ce code n'est pas sourcé, voir docs/fidelite.md v2.8 (A-30)
# Commande: Get-Certificate -Template Machine (CertSvc arrêté sur l'autorité LAB-SRV1-CA)
Le serveur RPC n’est pas disponible (1722, RPC_S_SERVER_UNAVAILABLE) : le service Services de certificats Active Directory (CertSvc) est arrêté sur l’autorité LAB-SRV1-CA.
